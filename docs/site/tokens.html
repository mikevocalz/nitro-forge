Tokens and rebrand

A brand changes three keys per scheme: accent, ink and soft. Everything else is locked or deferred.

Rebrand contract

The file is brand.theme.json, separate from tooling/brand/brand.schema.json (decision 24). Minimum override: 3 keys by 2 schemes, 6 values.

KeyFeedsSuite darkSuite lightPrism darkPrism light
accent--color-primary, --color-accent, --color-focus#B7A5FF#6950D1#66B9FF#086CB8
ink--color-on-primary#211A3D#FFFFFF#081D2F#FFFFFF
soft--color-primary-tint#38304F#EEE9FF#173C59#D6EAFB

Two channels carry a brand

A rebrand needs both. The CSS variables reach the NYC-Tron controls. The JS overrides reach the Forge components that read colours in JavaScript.

ChannelCallReachesDoes not reach
CSS variablesbrandCssVariables(theme, scheme) on a [data-brand] block, :root or a TokenScopeEvery NYC-Tron control (Button, TabBar, SegmentedControl, Select, Banner) and Tailwind utilities reading --color-primary, --color-accent, --color-focus, --color-on-primary, --color-primary-tintColours Forge reads in JavaScript
JS overridesbrandThemeOverrides(theme, scheme) as themeOverrides on ForgeWorkspaceWorkspace header, rail label, studio glyphs and the soft chip behind them. PersonaTurret reads colors.accent and PersonaComposer reads colors.accent and colors.soft from their own colors prop, which ForgeWorkspace does not fill: pass the same overrides to themThe CSS variables

Neither channel reaches PrismEditor, QuillTextEditor, ForgeDocumentStage or the default ForgeIcon palette. Applying only the CSS variables recolours the controls and leaves the workspace header, glyphs and persona turret on the old accent.

Deferred

The six neutral keys wait for an owner-supplied contrast check (decision 23): base, raised, deep, line, text, muted. The checker does not measure them. A radius override is struck: chrome keeps 4 px (AGENTS.md).

Locked

  • status colours (danger, on-danger, info, success)
  • paper tier
  • radius
  • space
  • type
  • motion
  • hit targets
  • instrument and chrome tiers (derived from Prism override)
  • document colours (swatches, artboard checker)

Drift

Kept as separate tokens. Unification changes pixels and is the owner's call (decisions 5 and 20).
