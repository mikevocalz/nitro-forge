Install order

Nothing here is published to npm. Steps 1 to 3 cannot be reproduced outside the monorepo today: no tarball or release exists for ignition, the engines, studio-layout or editor-controls. Source: install-order.md.

Agent prompt

Prompt
Install a Nitro Forge studio in this order: 0 Toolchain; 1 @nitro-forge/ignition native host; 2 An engine package, for example @nitro-forge/tally; 3 @nitro-forge/studio-layout; 4 @nitro-forge/icons through item forge-icon; 5 NYC-Tron tarballs; 6 Theme CSS; 7 StudioUIProvider and host; 8 Studio components. Steps 1 to 3 work only inside the monorepo today. Stop and ask instead of inventing a release URL. Install the provider and host before any studio component.

The chain

  1. 0

    Step 0. Toolchain

    Node >=24.3.0, pnpm 12.18.0, Rust with cargo, Xcode for Apple, Android NDK and cargo-ndk for Android.

    registry add: no

    Commands
    corepack enable
pnpm install --frozen-lockfile --ignore-scripts

    CI runs these two on Node 24 (.github/workflows/ignition-v1-integration.yml). rustup targets and cargo-ndk have no stated install command.

  2. 1

    Step 1. @nitro-forge/ignition native host

    Native module, Nitrogen output and the Rust archives. shadcn cannot run nitrogen, pod install or CMake.

    registry add: no

    Commands
    pnpm install --frozen-lockfile
pnpm --filter @nitro-forge/ignition codegen          # nitrogen; output is committed, regenerate only after a spec change
pnpm --filter @nitro-forge/ignition typecheck
pnpm --filter @nitro-forge/ignition exec vitest run tests/nitro-host.test.ts
cargo test --locked -p nf-sys && cargo build --locked -p nf-sys
    Commands
    bash packages/ignition/scripts/build-apple.sh        # writes packages/ignition/native/ForgeRust.xcframework
ANDROID_NDK_HOME=/path/to/ndk bash packages/ignition/scripts/build-android.sh   # default ABIs: armeabi-v7a arm64-v8a x86 x86_64, platform 24
bash packages/ignition/scripts/build-android.sh arm64-v8a                       # a subset
  3. 2

    Step 2. An engine package, for example @nitro-forge/tally

    Workspace dependency. Every engine is in the one Rust archive from step 1.

    registry add: no

    Commands
    "@nitro-forge/tally": "workspace:*"

    A line in the app's package.json. apps/example/package.json lists all of them.

  4. 3

    Step 3. @nitro-forge/studio-layout

    Private, pure TypeScript, no build step. Needed for the Studio type and the dock model.

    registry add: no

    Commands
    "@nitro-forge/studio-layout": "workspace:*"

    A line in the app's package.json. No tarball exists.

  5. 4

    Step 4. @nitro-forge/icons through item forge-icon

    Copies the icon source and adds react-native-svg when it is missing.

    registry add: yes

    Commands
    npx shadcn@4.23.0 add @nitro-forge/forge-icon

    Run against a local server only. The GitHub URL needs a release tag.

  6. 5

    Step 5. NYC-Tron tarballs

    GitHub release assets, pinned in tooling/nyc-tron.json. The packages cannot be installed by shadcn. Registry items that wrap them can.

    registry add: partly

    Commands
    https://github.com/mikevocalz/NYC-Tron-UI/releases/download/v1.0.0-rc.2/nyc-tron-<name>-1.0.0-rc.2.tgz
    Commands
    pnpm verify:nyc-tron                                  # node tooling/verify-nyc-tron-pin.mjs: manifests and lockfile use the pinned URL
node tooling/verify-nyc-tron-pin.mjs --download       # also re-hashes the release assets

    Exact URLs and sha256 values are in tooling/nyc-tron.json.

  7. 6

    Step 6. Theme CSS

    NYC-Tron ships no colours. The generated CSS declares the variables its components read.

    registry add: partly

    Commands
    pnpm --filter @nitro-forge/studio-workspace build:theme
npx shadcn@4.23.0 add @nitro-forge/studio-theme

    The add copies theme.ts, theme.css and theme.native.css. The CSS entry import is app code (install-order.md step 6).

  8. 7

    Step 7. StudioUIProvider and host

    Every studio component throws at first render without the provider.

    registry add: partly

    Commands
    npx shadcn@4.23.0 add @nitro-forge/studio-ui-provider @nitro-forge/nyc-tron-host

    Wiring the 27 slots is app code. See apps/example/src/studio-ui.tsx.

  9. 8

    Step 8. Studio components

    Only now do the studio chrome items work.

    registry add: yes

    Commands
    npx shadcn@4.23.0 add @nitro-forge/forge-workspace

    Other items are listed on the home page.

Known gaps

  • No document today gives these steps in order. This file is the first.
  • Steps 1 to 3 cannot be reproduced outside the monorepo: no tarball or release exists for ignition, the engines, studio-layout or editor-controls.
  • NYC-Tron's published registry.json (on its agent-native-20261119 branch) still lists forge/inputs/PrecisionScrubber and has no shell/PrecisionScrubber, so prism-editor's @nyc-tron/shell/PrecisionScrubber dependency does not resolve until NYC-Tron rebuilds its registry. check-imports.mjs reports it.
  • The Apple archive script and the integration doc disagree on Intel simulator support (step 1).
  • Seven NYC-Tron packages are pinned; the example installs four. Which of the other three a new studio needs is not stated in the repo. UNVERIFIED.

No verify command is stated in the repo for any step. UNVERIFIED.
