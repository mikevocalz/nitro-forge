Nitro Forge

Document studios on one Rust engine, delivered as a shadcn registry of source files plus monorepo packages. General controls come from NYC-Tron; the editor controls are @nitro-forge/editor-controls.

Status. The registry is built: 18 items in r/. The registry URLs point at the moving branches master (Forge) and main (NYC-Tron), not a release tag, so what shadcn add fetches changes with each push until the owner cuts tags. The @nyc-tron items resolve only once NYC-Tron's r/ is on its main branch. Packages are at 0.1.0, no tag or tarball has been cut, and nothing is on npm. Steps 1 to 3 of the install cannot be reproduced outside the monorepo today. See step 1.

Registry items

Needs StudioUIProvider (8)

  • Forge Document Stage. Workspace chrome: read-only stage of live engine state (text, cells, slides, tracks, shapes). Needs StudioUIProvider and studio-layout. Accessibility: source read, failures found.
  • Forge Workspace. Workspace chrome: header, undo/redo toolbar, docks, floating panels, status line. Needs StudioUIProvider, @nyc-tron controls, studio-layout. Accessibility: source read, failures found.
  • NYC-Tron Host. Provider adapter: nycTronStudioUI() maps @nyc-tron controls onto the StudioUIProvider slots. Needs the @nyc-tron tarballs installed. Accessibility: not reviewed.
  • Persona Composer. Persona form: name it, order instruments, pick capabilities, save, export, import. Needs StudioUIProvider and a PersonaStore. Accessibility: source read, failures found.
  • Persona Turret. Persona switcher dial with four stops. Drag or arrows preview, Enter commits. Needs StudioUIProvider, studio-theme, forge-directions. Accessibility: source read, failures found.
  • Prism Canvas. Artboard: transparency checker, selection outline, one-finger drag to move bounds. Needs StudioUIProvider and studio-gesture. Accessibility: source read, failures found.
  • Prism Editor. Vector canvas editor: shape tools, layers, transforms, personas. Needs ignition and editor-controls first, StudioUIProvider, @nyc-tron. Accessibility: source read, failures found.
  • Quill Text Editor. Writing surface: draft applied as one edit, conflict on outside change. Needs StudioUIProvider and a Quill document with apply and reload. Accessibility: source read, failures found.

No provider needed (10)

  • Studio UI Provider. Provider: StudioUIProvider supplies the 27 UI slots. Every studio component throws without it. Fill the slots with nyc-tron-host. Accessibility: source read, no failures found.
  • Studio Theme. Theme: dark and light tokens, densities, generated theme.css (Tailwind v4) and theme.native.css (Uniwind). build:theme regenerates both. Accessibility: source read, failures found.
  • Brand Theme. Rebrand contract: brand.theme.json schema and a validator. A brand sets accent, ink and soft per scheme (3 keys). Neutrals, radius and status colours stay locked. Needs studio-theme. Accessibility: not reviewed.
  • Forge Directions. Theme: workbench, optics and atelier palettes for Prism chrome and the persona turret, plus WCAG contrast helpers. Needs studio-theme. Accessibility: source read, no failures found.
  • Forge Icon. Icon: outline when idle, filled when selected. 47 glyphs drawn; 42 of 1,463 catalog ids resolve to one; 6 drawn glyphs are not catalog ids. A name with no glyph renders nothing. Needs react-native-svg. Accessibility: source read, failures found.
  • Forge Icon Button. Icon: pressable ForgeIcon with a 44 by 44 hit target. Throws TypeError on a blank label. Same file as forge-icon, so this item installs forge-icon. Needs react-native-svg. Accessibility: source read, failures found.
  • Instrument System. Instrument policy, not UI: 18 blueprints, precision scrubbing math, ruler ticks, motion budgets, overlay planner. No provider needed. Accessibility: source read, no failures found.
  • Persona Model. Persona data, not UI: 4 personas, 11 capabilities, 7 surfaces, compose, import, export, per-document store. No provider needed. Accessibility: source read, no failures found.
  • Studio Gesture. Gesture primitive: one-finger pan recognizer, PanResponder on web, Gesture Handler on native. No provider needed. Accessibility: source read, no failures found.
  • Workspace Utilities. Helpers, not UI: APP_MANIFESTS (task line, glyph, category per studio), jsonProblem (JSON parse error as a sentence). Needs studio-layout. Accessibility: source read, no failures found.

Not in the registry

4 binding adapters, 12 engines and 3 foundations (ignition, studio-layout, editor-controls). Each has a reason in registry-excluded.json.
