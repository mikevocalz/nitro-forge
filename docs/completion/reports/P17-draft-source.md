# P17 Draft: bounded 2D source backend

Draft appends kind/tag10 after Design9 without changing tags0..9. Persistent schema1 owns world points, ordered segments, linear constraints and world snap settings. It uses unchanged NFD1 framing; snapshot opening uses the shared owning helper. No public package pin, default product or native runtime is activated.

The solver admits fixed/coincident/horizontal/vertical and signed axis-distance equations only. It reports rank, coordinate DOF, maximum absolute residual and unsatisfied IDs. Consistent bounded geometry commits atomically; inconsistent/invalid attempts preserve geometry/history. Free coordinates retain authored values. Exact locked point/segment-endpoint coordinates are restored before residual/status recomputation and skipped defensively on publication, so user tolerance cannot drift a lock. This is a bounded linear coordinate solver, not general nonlinear CAD.

Grid/endpoint/midpoint/projection/unique finite intersection snaps return actual world positions and distances with inclusive world tolerance. Exact computed-distance ties use fixed mode priority then source IDs. Endpoints include every authored point; other feature snaps use visible segments. Collinear/nonunique/nearparallel intersections and degenerate projections are excluded. Distinct coincident point IDs remain valid; zero-length segments produce no stroked pixels. Screen tolerances must be converted by the host's actual invertible viewport; no screen transform or selection is stored in the model.

Source revision advances only on actual publication/undo/redo/restore. Revision-bearing reads reject in staged batches, preventing intermediate revision results escaping a single outer revision. Complete candidate validation and sixteen Arc/COW history entries use bounded IDs/counts/coordinates, an 8 MiB state cap,128 variables/384 rows and bounded elimination work. See ENGINE_OPS for exact operations and limits; these logical budgets are not measured RSS evidence.

Rendering validates the complete supplied world viewport and projected coordinates/stroke widths against Prism's public limits before compositor/output allocation. Actual Prism path rendering supplies JSON/base64 or binary RGBA. A read may reject unsupported projected extents; it never substitutes mocked pixels. Cooperative tasks checkpoint between paths and before/after flatten, not inside the synchronous compositor.
