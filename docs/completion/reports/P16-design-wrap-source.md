# P16 Design fixed-size wrapping checkpoint

Extends the authoritative Design9 evaluator with real ordered row/column wrapping. Canonical NYC-Tron source AutoLayoutInspector advertises direction, gap, all four paddings, wrap, align and justify; each now has engine behavior. The installed alpha.4 package does not expose this newer design subpath. No inspector, application route or default host was activated. HugFillFixedSizeControls is a separate intrinsic/dependency evaluator feature and remains unsupported; no hug/fill setting is accepted or silently ignored.

A line greedily accepts the next fixed-size child when its size plus required gap fits the padded main axis. Otherwise it starts a new line. An oversized child occupies its own line and visibly overflows. Each wrapped line uses the maximum authored child cross size; cross alignment/stretch operates within that line and main justification is evaluated independently per line. Gap also separates lines. Wrapped lines start at leading cross padding; there is no cross-line distribution setting. Hidden children keep their layout space. Nonwrap layout keeps its existing full-content cross-axis behavior, and authored child geometry never changes during evaluation. Frames still do not clip.

Schema1 layouts missing wrap deserialize as false. False is omitted during serialization, retaining the old nonwrap representation; true requires the updated reader. Null/wrong types reject before state/history replacement. Existing full candidate/evaluated-box validation includes hidden nodes, Prism global bounds, effective nested padding and output budgets. Lock/history/visibility/window contracts are unchanged.

Focused verification: `CARGO_INCREMENTAL=0 cargo test -p design-engine` passes eleven tests, including three new cases for exact padded fits, row/column breaks, cross gaps, unequal cross sizes/stretch, independent justification, real two-line RGBA pixels, oversized hidden children, legacy default, invalid update/restore and undo/no-op/redo. An initial test fixture used a frame too small for its own padding and failed during setup; the valid fixture was corrected before the final passing run. Direct installed TypeScript checking for packages/design and scoped git diff --check pass. No dependencies, registry IDs or native codegen changed; no native build or broad P19 run was performed.

This checkpoint adds one bounded layout capability. It does not complete P16, supply text/intrinsic layout, constraints/components/variables/prototypes or establish runtime/native acceptance. The parent reviewed the evaluator and compatibility behavior before committing this checkpoint.
