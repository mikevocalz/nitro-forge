# P03 — decoder and playback foundation (in progress)

## Native decoder checkpoint

Tron `c903eba` adds Android MediaExtractor/MediaCodec probing, frame output with
real presentation timestamps and file-backed interleaved Float32 PCM. It applies
codec preroll and phase-continuous linear resampling; frame conversion handles
crop/strides, SDR color range and rotation. A serial worker owns resource/cache
lifetime, with execution, output and disk budgets. DRM/HDR and unsupported format
changes reject explicitly and remain outside this checkpoint's proven formats.

The generated H.264/AAC fixture exposed seek-boundary sample loss on both OSes.
Android now decodes preroll before trimming. The iOS AVAssetReader also decodes
preroll/converter tail and trims returned PCM using timestamps.

Fresh native builds and runtime checks pass on both simulators. At a 125000us
request, iOS returned its actual 100000us presentation frame; Android returned
150000us. Both produced a 96x64 JPEG and exactly 12000 mono Float32 sample frames
at 24000Hz for a 500000us span, with 440 sign crossings from the generated 440Hz
tone. Past-end errors and deletion of generated cache outputs passed.
