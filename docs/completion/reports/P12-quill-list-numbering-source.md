Typed kind/format/shift operations update a complete candidate before one journal entry; equal requests preserve redo/events. Same-ID definition copies must agree. Limits are10000 list paragraphs/256 explicit definitions and OOXML-compatible instance IDs. Run text and every Style field survive membership edits, split/newline, merge, delete/replace and Unicode case changes. Body/plain-text output never gains literal marker prefixes. DOCX writes actual paragraph numPr/ilvl/numId, abstract and concrete numbering definitions, numbering.xml, document relationship and content-type override. Direct level definitions and instance references follow the [Open XML Level](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.level?view=openxml-3.0.1) and [LevelText](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.leveltext?view=openxml-3.0.1) contracts. Import/export preserve explicit numbering IDs, level settings and startOverride restart instances. Actual ZIP/XML and structural roundtrips were tested; no Word/native visual acceptance was run. Canonical preview uses reset-on-shallower behavior, consistent with Microsoft's documented [Word restart behavior](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/140a2cd9-2f26-456d-9760-ae6ecef4e8b5); generic OOXML consumers may implement the standard's narrower omitted-restart rule.

The parser admits direct current-level numeric templates, explicit supported Unicode bullet glyphs and direct start/indent/hanging. Symbol-font/picture bullets, custom/compound templates, full overrides, style-inherited numbering, paragraph indentation overrides and numbered heading/quote combinations reject explicitly. Missing refs, bad levels, duplicate properties, unsupported namespaces/attributes and malformed templates reject before replacing a live document. Numbering XML is capped4MiB/100000 events, relationships1MiB, inspected styles4MiB; existing document XML256MiB remains. Relative part targets are bounded local basenames. Logical bounds do not establish parser-security/RSS acceptance.

Legacy export writes real bullets with a reserved sentinel name. Import collapses that sentinel back to absent metadata only for the complete exact nine-level default template, level0 and contiguous use; foreign/changed settings are not silently erased. A ListParagraph style alone imports as unnumbered para, preserving the absence of actual numbering.

The typed adapter supplies all real list-kind choices and format/shift callbacks for coherent contexts, including prior same-instance items and correct selected indices. Current canonical preview always starts at one and cannot represent mixed/nondefault-start marker output; those projections reject honestly. The native APIs/DOCX retain custom starts. No UI or pin was activated, no intrinsic font/marker layout was invented and no H-07/P12 acceptance was promoted. Root is considering an authoritative-marker control extension as a separate gated slice.

## Snapshot compatibility protection

Explicit list metadata now causes snapshot() to emit `{kind:'quill',schema:2,document:{blocks}}` inside the existing NFD1 envelope. Omitting root blocks makes the actual pre-list deserializer shape reject, preventing silent loss through ignored unknown Block fields. The new reader validates wrapper kind/schema/shape and full list/style state before replacement; malformed, foreign or future wrappers preserve state/history. Documents without explicit list metadata retain byte-exact legacy snapshot encoding where values remain unchanged, including absent-metadata legacy list blocks. No global format version or native/checkpoint ordinal changed.

Focused compatibility tests exercise real snapshot/reopen, an old-reader root/Block shape (including proof it would accept the unsafe unwrapped shape), exact legacy bytes and foreign/future/invalid-wrapper rejection preserving redo. `CARGO_INCREMENTAL=0 cargo test -p quill-engine lists::snapshot_version_tests` passed all three focused cases; the subsequent full Quill run passed all60 tests.
