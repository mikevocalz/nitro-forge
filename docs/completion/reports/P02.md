# P02 — shared platform/document infrastructure (in progress)

## N-18 native telemetry checkpoint

The standalone native consumer now includes the recovered telemetry package and
an explicit `Verify native telemetry` action plus automatic acceptance entry
(`FORGE_ACCEPTANCE=telemetry`). The real Cadence JSI probe passed on iOS 27.1
iPhone Duo and Android API 36 ARM64. It validates off/local/diagnostics behavior,
real engine timings and typed failure codes, absence of the test track-name
payload, failure-message exclusion from diagnostic batches, consent revocation
and cleanup. Diagnostic batches are captured in memory; no network sink or
automatic production diagnostics was enabled. Captured results:
[iOS](../evidence/P02-ios-telemetry.txt),
[Android](../evidence/P02-android-telemetry.txt).

The standalone frozen install, app and acceptance typechecks and three Metro
regressions pass. This is a JavaScript integration exercised on existing native
transaction binaries; it does not claim the later Folio/Pitch restore fix is
present in those installed binaries. Product consent/export UI, authenticated
sink delivery and the other target hosts remain unfinished. P02 remains open.

## N-11 revision collaboration checkpoint

The new shared document owner adds explicit revision checks, atomic provider
compare-and-swap, dirty/conflict preservation, clean-peer adoption and lost-ACK
recovery without replacing the board's Yjs owner. Nine tests drive real Rust
engines with a transport contract fixture. Folio and Pitch were found to retain
history across restore; both now reset it after successful decoding. The full
Rust workspace passes 348 tests including an all-engine restore/history test.
See [N11-collaboration.md](../N11-collaboration.md) for contracts, tested behavior
and remaining backend/CRDT/product/device gates. P02 is still in progress.

## N-15 transaction checkpoint

All seven Rust engines now implement bounded atomic `__batch` commands. A
failed step leaves document state and history unchanged; successful mutations
produce one undo entry. Read-only batches preserve redo. The TypeScript gesture
coordinator owns bounded immutable previews, rejects stale gesture tokens and
serializes accepted commits and history operations. Cadence's gain/pan pad
commits both parameters together and starts without setup edits in user history.

Validation: 347 Rust workspace tests, 18 selected host/autosave/transaction
tests and four Cadence session tests passed, along with affected typechecks.
Fresh Rust archives built for three Apple targets and four Android ABIs; fresh
iOS simulator and Android application builds passed. The real native transaction
probe passed on both platforms, including all seven engines, failed-step rollback,
redo preservation, cancelled/stale gestures and paired gain/pan undo/redo. See
[iOS](../evidence/P02-ios-transactions.txt) and
[Android](../evidence/P02-android-transactions.txt).

A real Android pad drag changed gain/pan from 1.00/0.00 to 0.50/0.61; one Undo
restored both and Redo reapplied both. The native services probe also passed with
typed cancellation normalization. The later manual iOS pad check was interrupted
by a dead simulator tool transport; its earlier automated native transaction
result remains valid. This checkpoint does not claim eight-platform acceptance.

The document-lifecycle audit found that all seven public engine wrappers could
retain an unpublished native session after a failed import, initialization or
snapshot restore. They now use one shared initialization owner that closes on
failure and preserves both errors if cleanup also fails. Three lifecycle
regressions and typechecks for all eight affected packages pass.

N-18's unmerged telemetry package was recovered from
`origin/feat/test-telemetry-adapter-20261105`, then audited against the current
host. Consent revocation now invalidates outstanding spans, flush drains
automatically dispatched sink work, capacities are validated, retained events
are immutable and host disposal clears instrumentation metadata. Fifteen tests
(including real Rust Prism flows) and typechecking pass. No external sink has
been configured. Native telemetry acceptance and product consent controls remain
unfinished; the earlier native engine probe is not telemetry acceptance.

First audited scope: N-13 LongTaskScheduler, N-14 MediaCache and N-16
NativeBinaryTransport. Their existing generated/native implementations are
reused. A new lazy `createNativeForgeFactory()` entry point and public task,
cache and binary-result types expose the production resource API without
loading Nitro during Node/web module imports. Resource ownership remains
explicit: the consumer closes documents/caches; tasks retain accepted work.

The native lab now runs **Verify native services** against the actual JSI
factory. On the fresh P01 iOS binary it passed:

- Cache capacity validation, least-recently-used eviction, accounting,
  remove/clear/close and rejection after close.
- Cache input and output ownership: changing caller buffers after put, or
  changing returned buffers, does not alter stored bytes.
- Raw Prism pixels through ArrayBuffer, immediate caller-buffer mutation,
  flatten output bytes and rejected unrelated sidecars without mutation.
- Native task completion/progress, raw NFD1 output and repeatable settled
  results.
- Cancellation of a long Cadence render with unchanged document state.

[The captured accessibility tree](../evidence/P02-ios-services.txt) records
the passing native result. Native binary provenance is in P01-artifacts.json;
P02 changes so far are TypeScript/public exports and the executable native
probe, with no change to the compiled native implementation. App and Ignition
typechecks pass; seven host regression tests pass. These are separate from
the actual simulator result above.
