# P02 — shared platform/document infrastructure (in progress)

First audited scope: N-13 LongTaskScheduler, N-14 MediaCache and N-16
NativeBinaryTransport. Their existing generated/native implementations are
reused. A new lazy `createNativeForgeFactory()` entry point and public task,
cache and binary-result types expose the production resource API without
loading Nitro during Node/web module imports. Resource ownership remains
explicit: the consumer closes documents/caches; tasks retain accepted work.

The native lab now runs **Verify native services** against the actual JSI
factory. On the fresh P01 iOS binary it passed:

- Cache capacity validation, least-recently-used eviction, accounting,
  remove/clear/close and rejection after close.
- Cache input and output ownership: changing caller buffers after put, or
  changing returned buffers, does not alter stored bytes.
- Raw Prism pixels through ArrayBuffer, immediate caller-buffer mutation,
  flatten output bytes and rejected unrelated sidecars without mutation.
- Native task completion/progress, raw NFD1 output and repeatable settled
  results.
- Cancellation of a long Cadence render with unchanged document state.

[The captured accessibility tree](../evidence/P02-ios-services.txt) records
the passing native result. Native binary provenance is in P01-artifacts.json;
P02 changes so far are TypeScript/public exports and the executable native
probe, with no change to the compiled native implementation. App and Ignition
typechecks pass; seven host regression tests pass. These are separate from
the actual simulator result above.

Remaining: autosave/recovery, gesture transactions, collaboration and the
remaining N infrastructure integrations/acceptance, including native Android
and the other required platform hosts. N-13/N-14/N-16 are **not** marked fully
complete across all required platforms by this iOS checkpoint. Android's
userdata storage gate is tracked in P01; independent implementation continues.

Update: the Android storage gate has resolved. The same native services probe
passed on the API 36 ARM64 emulator, including cancellation and ownership;
see [P02-android-services.txt](../evidence/P02-android-services.txt).

Autosave now serializes real NFD1 checkpoints, retains dirty state after failed
storage, captures edits arriving during a write, and recovers into a new engine
session. Undo/redo now notify document observers. Five regressions execute real
Cadence Rust operations; the combined host/autosave selection passes 16 tests.

The companion NYC-Tron branch implements native staged checkpoint generations
with CRC32 corruption fallback and a retained last-good generation, plus web
IndexedDB transactions. The actual Chrome test passed ownership, forced abort
after request success, prior checkpoint retention, fresh connections, close
and page-reload persistence. Fresh iOS and Android builds passed disk/relaunch
acceptance, interrupted-write isolation, corrupt-generation fallback and a
real native I/O failure followed by retry. Captured results are in
[iOS](../evidence/P02-ios-checkpoint-latest.txt),
[Android](../evidence/P02-android-checkpoint-relaunch.txt) and
[Chrome](../evidence/P02-web-storage.txt).
The opt-in checkpoint lab typechecks against the actual companion declarations;
the default alpha.4 consumer stays on its released exports.

Adding the platform-services consumer exposed missing SwiftPM linkage metadata.
The companion now ships Package.swift preserving AVFoundation, CoreMedia,
UniformTypeIdentifiers and iOS 16.4 from its Podspec. A persisted alpha.4 patch
keeps the consumer build reproducible. The generated Expo SwiftPM manifest was
inspected and retains all three frameworks. A source/packaging regression and
Swift package manifest parsing pass. No app window/orientation contract changed.

The companion implementation is committed in NYC-Tron `55126d6`. All 25
platform-service regressions, typecheck/build and candidate package contents
passed. This completes the checkpoint-storage implementation/acceptance
checkpoint within P02; the phase still includes gesture transactions,
