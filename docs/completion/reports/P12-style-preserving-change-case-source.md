# P12 style-preserving case conversion

Implemented Quill `changeCase` for lower, upper, sentence and capitalize modes over a selected Unicode-scalar range across runs and blocks. Expansions retain the originating scalar's complete style; text outside the selection and paragraph kinds stay unchanged. The operation builds a validated replacement span and records one undo entry before mutation. Unchanged/collapsed conversions are eventless and preserve redo. It returns an adjusted selection end for expansions; the canonical ribbon callback refreshes against that range rather than reusing stale offsets.

Lowercase uses the actual Rust full-paragraph Unicode lowercase result, including context outside the selection and across style boundaries, aligned back to source scalars by their individual lowercase expansion lengths. Tests compare split-style output against actual full-string lowercase for Greek final sigma, case-ignorable marks/apostrophes and dotted-I expansion. Alignment mismatches reject. This is locale-independent default casing, not locale-specific Turkish/Lithuanian behavior. Uppercase and initial capitalization use default mappings, not Unicode titlecase.

Capitalize uses explicit alphanumeric/combining-mark/apostrophe word units. Sentence mode uppercases the first alphabetic scalar of each selected paragraph span and after ASCII .!? followed by whitespace; these are editing grammars, not UAX29/linguistic segmentation. Context bytes and converted selection output each cap at 1 MiB; affected structure caps at 4096 blocks/65536 runs before cloning. No process RSS claim is made.

The direct dependency unicode-normalization is pinned to the already locked/cached 0.1.25 source, MIT OR Apache-2.0. Its source helper explicitly classifies General_Category=Mark. Only that classification is used; the operation does not normalize user text. The MIT option and notice are retained in packages/quill/THIRD_PARTY_NOTICES.md. Cargo.lock adds only this existing package as a Quill dependency, without a new version/download.

All 46 affected Quill engine tests pass, including five new case tests covering styled expansion/adjusted selection/DOCX roundtrip, hyperlink metadata retention, contextual Unicode across boundaries, multiple blocks and mode grammar, no-op/history and oversized-output rejection. All ten office adapter tests pass, including adjusted-selection callback rebinding and returned selection metadata, and Quill TypeScript checks pass. The binding exposes its actual selection so the host can synchronize caret/range after expansions. Pinned RichTextRibbon onChangeCase is the actual exposed callback; its consumer type contract is updated. This source slice does not claim activation in an application host. No native build, broad platform suite or phase/component acceptance promotion occurred.

Remaining P12 work includes list definitions/levels, bookmarks, rendered pages and full native editing/font/speech/layout workflows. Existing DOCX serialization capabilities are unchanged: case conversion preserves engine hyperlink metadata, but this slice does not add missing hyperlink serialization support.
