# P17 Draft: command and anchor-guide source

This follow-up adds actual world-anchor ortho/polar projections and a bounded parser over the registered Draft engine. It changes no dependency, registration, public pin, solver, native runtime or default product activation.

Ortho candidates project onto the anchor's bidirectional horizontal/vertical axes. Polar candidates project onto legal forward rays at integer multiples of the configured increment below 360°, with behind-ray projection clamped to the anchor. Increment bounds are 0.01..360°. Neighboring angular rays plus first/last wrap rays suffice; no large ray scan or modulo-generated illegal direction is used. Exact computed distance wins, followed by mode/source/angle order; every candidate must fit the world tolerance. No supplied anchor means no guide candidates. Old snapshots default both flags false and increment 45°.

The explicit ASCII grammar supports POINT, LINE, SEGMENT, absolute MOVE, DELETE POINT/SEGMENT/CONSTRAINT, SOLVE and SNAP. Input is capped at 4096 bytes/eight tokens/64 bytes per token. It never evaluates code, expressions or arbitrary commands. LINE stages the real two-point/segment operations and commits one journal step; partial failures retain the original state/counter/redo. Other commands use their existing model operations and locks. SNAP aliases cannot bypass the staged-batch source-revision restriction. Inconsistent SOLVE commands reject with the actual report; underconstrained consistent results remain labeled.

Typed bindings match the inspected current DraftingCommandLine and ObjectSnapsAndOrtho source callbacks. A host supplies current-session ownership, shared admission, history/input callbacks and its actual viewport feedback; no second canvas or optimistic geometry is created. Queued aborted work is rejected before dispatch, without promising rollback of an accepted atomic command. Failed commands reject so the canonical control retains its input. Snap hosts must supply authoritative sourceRevision and the full revision-tagged query; stale/closed-session candidates are withheld. The alpha.4 package does not include these CAD exports, so source binding is separate from publishing/pinning/actual host adoption.

Validation: the complete Draft Rust suite passes 11 tests, including nondivisor 100°/350° rays,360° single-ray/behind-ray cases, zero delta, smallest increment, ortho ties/tolerance, legacy defaults, staged LINE rollback, actual command-created and moved Prism pixels, history/reopen and command-SNAP batch rejection. Typed binding tests pass 4 cases, including late old-revision feedback and queued cancellation. A real CLI binding test verifies command-created pixels, one-step undo/redo, rejected unsupported input, anchor query and owned snapshot reopen. Direct typechecks/static checks pass. Tests use a task-only alias to the real Ignition source for the uninstalled workspace link; they do not validate an installed/published CAD consumer. No native target or full P19/P20 run was performed. P17 remains incomplete.
