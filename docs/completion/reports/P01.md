# P01 — native runtime bootstrap (in progress)

The standalone Cadence app now constructs the production `createNitroHost()`
instead of requiring a global factory registration that its entry point never
performs. Failed initialization, cancelled initialization and effect cleanup
dispose the host and its native documents. Cleanup rejections are observed.
The existing default orientation and platform identifiers are preserved.

The lab's **Verify native engines** action runs the real production host. For
each of Prism, Cadence, Splice, Folio, Pitch, Tally and Quill it initializes a
document, describes it, checks the NFD1 snapshot envelope, restores it, compares
state, rejects corrupt input without changing state, and closes the document.
It also checks Cadence gain/pan edits, undo, redo and reopening a saved snapshot
in a second native document. This is an executable native acceptance probe,
not a mock test or a claim of complete component acceptance.
