   was regenerated in-worktree:

   (ReactNative 0.88.1 SPM artifacts were already in
   ~/Library/Caches/ReactNative/spm-artifacts/0.88.1; NitroForgeV1 was
   autolinked as a self-managed local package pointing at
   packages/ignition/native/ForgeRust.xcframework.)
2. First xcodebuild failed compiling react-native-video
   (tooling/react-native-video-v1/experimental-build-v1.tgz):
   ios/core/NowPlayingInfoCenterManager.swift calls runOnMainThread, but
   the Nitro v1 port deleted ios/core/Utils/RunOnMainThread.swift (see
   tooling/react-native-video-v1/
   react-native-video-beta12-nitro-v1-experimental-1-recovered.patch:2400,
   which shows the removed file). This is a pre-existing tgz defect at
   HEAD, unrelated to the scene engine; the Android build is unaffected
   (Kotlin Threading helper). Local-only repair, NOT committed:
   restored ios/core/Utils/RunOnMainThread.swift inside the installed
   node_modules copy of react-native-video with the exact upstream content
   (runOnMainThread + runOnMainThreadSync). After that BUILD SUCCEEDED.
   Recommend a follow-up: repack experimental-build-v1.tgz or patch
   NowPlayingInfoCenterManager.swift upstream.
