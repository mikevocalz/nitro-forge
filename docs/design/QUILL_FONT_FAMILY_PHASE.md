# Quill direct font-family source checkpoint

Quill now stores an optional `font_family` on durable inline Style. `applyStyle` accepts a nonblank 1–128-character family or null to clear it. Control characters and XML-invalid BMP terminal code points reject before mutation. Existing snapshots without the field deserialize to None; restore validates the field before replacing state. Existing cloned inline undo records and run splitting/merging preserve the new value without a second history path.

DOCX exports direct Latin family as escaped w:rFonts ascii/hAnsi attributes and imports direct ascii (or hAnsi fallback), unescaping XML attribute entities before validation. Theme font resolution, distinct East Asian/complex-script fonts and installed font availability remain outside this model. A single-family model does not promise to preserve a DOCX containing separate script-family assignments.

The TypeScript Style and office binding expose the durable value, a mixed/unspecified selection state and onFontFamilyChange. Empty/collapsed selections keep the existing rejection behavior; no typing-style/caret provider was fabricated. Font size and highlight remain deferred. The source slice supplies engine behavior and a binding; it does not enable new app controls or claim font-aware shaping/layout. Existing engine layout remains its prior heuristic.

Examples: applyStyle(from, to, {font_family: 'Aptos'}) sets an explicit family; {font_family: null} clears it; a blank or overlong family rejects without changing the document. bindQuillRibbon(...).onFontFamilyChange(undefined) clears through the same operation and rereads the binding.

Validation performed: cargo check -p quill-engine, direct installed TypeScript compiler for packages/quill, rustfmt on the two changed Rust files and git diff --check passed. Cargo reports the existing unused base64_encode warning. No tests, DOCX runtime round-trip, editor runtime or native build was run under the component-review gate. Independent source review remains required before commit.

Unrun regression cases now cover durable set/clear with existing bold style, undo/redo, invalid patch atomicity with redo preservation, legacy snapshot default, valid snapshot restoration, invalid restore preserving both state and undo history, escaped DOCX family round-trip and clearing. Adapter cases cover mixed/inherited read state, set/clear payloads, collapsed-selection rejection and original engine rejection without publishing a refreshed binding. Shared mock fixtures remain unchanged; mixed fonts use a separate local fixture. The pinned NYC-Tron consumer type contract now includes fontFamily/onFontFamilyChange. `cargo check -p quill-engine --tests` compiles the new Rust cases without executing them; scoped TypeScript checking passes. Unrelated Rust formatting changes were removed.
