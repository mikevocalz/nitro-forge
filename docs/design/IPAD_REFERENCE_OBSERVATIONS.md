# iPad reference observations

2026-11-07. Initial visual review of official App Store iPad gallery previews retrieved through Apple’s US `iPadSoftware` search results. This is a reference audit, not hands-on app testing.

The review uses touch-first workflow and native/platform truth as criteria. Named designers and engineers in the design pack are standards of review, not participants or endorsers. The private pack and downloaded images remain outside this public repository.

## Evidence limits

- Inspected the first downloaded image for all 16 exact app matches; additional images are identified below. The separate Creative Cloud entry remains unresolved.
- These are small gallery previews, mostly marketing composites. An image’s outer orientation is not proof of the app viewport’s orientation. A tablet frame is not proof of an 11in or 13in device.
- The current listing version does not prove the screenshot’s build version. Neither image pixels nor supported-device metadata establishes the display used for capture.
- No gestures, menu behavior, accessibility, performance, persistence, processing result or physical Pencil capability was exercised.
- The requested landscape/portrait × 11in/13in matrix remains incomplete. No iPhone image was substituted for an iPad reference. Mobbin/Dribbble and App Store review research remain separate work.
- The public `reference-index.json` identifies the reference set and its gaps. Source asset URLs and hashes are indexed publicly for provenance; downloaded image files remain outside the repository in the private local capture directory.

## Affinity by Canva

Source: [Affinity by Canva iPad listing](https://apps.apple.com/us/app/affinity-by-canva/id6751323445?uo=4). Inspected gallery image(s): 1.

The first gallery image shows artwork between a narrow left tool rail and a right panel containing layer/property controls; a small command strip sits above the document. The active curve editor is part of the right-side workspace rather than a separate full-screen page. Adopt the division between persistent tools, contextual inspection and the document. Adapt the panel sizing to Forge’s actual pane geometry. Reject the assumption that a single landscape marketing image proves portrait, hinge behavior or a particular device size.

## Consequences for the first Forge design round

Use one real Prism task across all three directions: select an artwork layer, enter an exact opacity, inspect color, undo, save and reopen. Keep document tools distinct from app navigation. Use actual Cadence tracks and a real Splice time ruler to check whether the same grammar survives different content.

The references support compact surrounding chrome, bounded contextual instruments and task-specific composition. They do not pick a Forge material treatment or certify a direction. Render the existing Workbench, Optics and Atelier choices on the same task before choosing or changing tokens.
